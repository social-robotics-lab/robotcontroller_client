## オフライン検証との区別

Windows / CPython 3.12.10および3.14.3では、それぞれ135件のオフラインテストが成功している。[レビュー記録](review-report.md)を参照。これらはループバック・モックサーバー・仮想時計による検証で、実機試験の代替ではない。

本リリースの文書化作業でCodexが行うのはローカルの検証とGitHub上のリリース手続きだけである。Sotaへの接続・制御・音声再生・SSH・転送・デプロイ・サーバー起動停止、およびクラウド音声合成APIの実行は行わない。

以下は今回の報告から個別の実機受入完了とは扱わず、今後の追加検証事項とする。

- BUSYの動作。
- 切断後のストリーミング接続枠解放。
