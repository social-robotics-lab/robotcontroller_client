# サンプル音声

`sample.wav`は同梱の`generate_sample.py`で数学的に合成した440Hz・0.25秒の正弦波です。
24,000Hz、モノラル、signed 16-bit little-endian PCM WAVで、従来方式・新型ストリーミングの両方に利用できます。
最大振幅は2000/32768、両端10msにフェードを付けています。実機での音量は未検証です。

録音、音声合成サービス、第三者の音源・楽曲は使っていません。生成スクリプトと生成WAVは本リポジトリの[MIT License](../LICENSE)で提供します。

再生成はリポジトリのルートで以下を実行します。出力先はスクリプト位置を基準とするため、カレントディレクトリには依存しません。音声の再生やロボットへの接続は行いません。

```sh
python assets/generate_sample.py
```

旧`src/sample.wav`は44,100Hz・ステレオ・16bit PCMでした。Git履歴とリポジトリ内の資料では制作元・音源固有の再配布条件を確認できなかったため、現行ツリーから外しました。履歴は書き換えていません。
